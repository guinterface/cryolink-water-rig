# CryoLink WATER rig — build and integration order

This package is a class-prototype fabrication design, dated 2026-11-05. Test with open-reservoir water only. It retains22mm seat bores and28/46/30mm capture logic but uses opposed pins to open both poppets2mm. It does not demonstrate the flight B pressure-opening mechanism. The listed2.5mm-ID hose controls flow. STEP uses mm; assembly coupling axis is X, face x0, axis z110. Local wet-part axes are Z, rear datumz0, facez60. A rear isx-60; B rearx+60. All standalone STEP files have manufacturing coordinates, not arbitrary assembly offsets.

1. **Before fabrication, Nov5–6:** inventory actual borrowed servos, switches, boards, tubing and load cell; check SOURCES.md assumptions against calipers. Use Pololu1402 switches and Adafruit815 PCA9685; see FIX1 source evidence. Do not drill servo/switch mounts from assumed details; use slots/clamps and actual samples. Reserve PRL machine time and materials through the course. Wet-test host and machine access are still unconfirmed in the existing plan. No outreach has been performed by this run.

Clamp temporary shims to set the fixed approach datum at0/±5mm. The wedge rises1.222mm over70mm for1°. Shims set initial delivery error; remove any constraint that would prevent the floating plate self-centering. Repeat X/Y offset directions by rotating the shim fixture90°. There are no claimed calibrated print tolerances: measure every shim.
9. **Latch:** install the common4mmshaft behind B and the two hooks outside the cone. Rounded noses catch the B flange back face at -1° over-center; fixed stops carry the closed load. Command +30° to open. Maintain carriage preload during latch motion and drain before unlatching. Clamp each hook to the shaft using a transverseM3split clamp or actual horn connection; the pivot clearance cylinder alone does not key a shaft. Couple the supplied servo horn to the printed split adapter. Adjust rotation for contact without bending the housing. Set the seat switch from the B witness cam to assert only within the final~1mm. Set the latch switch from the actual hook position; it must remain false if a hook is blocked, even if the servo is commanded closed. Home switch reads the moving carriage flag at retracted travel. Adjust switches using the slotted side cheeks on their towers; set overtravel from the actual switch, then record it.
10. **Pinch valves and manual clamp:** fit4.7mm-OD silicone hose in each saddle; fit the smooth4mmjaw nose, spring and removable roof. The spring pushes the jaw closed. Fit a loose pull cord from each jaw through a smooth fairlead to the servo eccentric; opening takes up6mm, closing releases tension. Tune cord length with the servo detached. The modeled jaw stop gives about2mm collapsed gap versus2.2mm combined wall thickness. Fit/lock a positive stop after a coupon pinch test. Install a captiveM5nut in the manual clamp roof and a free pad under the screw. The clamp must be reachable beside the source. Geared servos can hold a cord taut without power: spring return does not establish power-loss fail-safe behavior.
11. **Plumbing:** reservoir → manual clamp → feed pinch → moving B rear → A rear → metal conditioning spool → manifold. Provide a slack, gently curved feed loop for the36mm carriage stroke and±5mm float. Put the drain outlet through its pinch to an open waste vessel, using the shortest practical downward branch. The fill outlet rises150mm above the manifold as a vented standpipe, then free-discharges into the receiver on the load-cell pan. Keep the discharge above the receiver surface to avoid a siphon. During conditioning the low-resistance open drain must hold manifold head below the standpipe crest; prove zero receiver gain before using this two-valve scheme. If it does not, the design requires an additional fill valve or rerouted/shortened drain: do not claim autonomous conditioning until corrected. Use the spare axial manifold port for the FIX2 pressure tee described below. Install actual washers at all10-32straight-thread joints; the CAD drill cylinders are not thread seals.
12. **Wall probe and electronics:** lightly clamp the6mmsheath tangent to the12mmmetal spool with thermal paste/foil. Keep the clamp conduction path short and repeat the same contact pressure between runs. Put the inlet probe in the reservoir. Keep the ESP32/PCA9685 behind the splash wall, away from wet plumbing; fit the board’s actual headers and right-hand mounting holes. Complete Lab64 soldering training before soldering. Use a separate current-limited5Vservo supply, MCU USB supply and common signal ground; verify simultaneous stall demand on the bench. DS18B20 bus needs the pull-up from the sensor wiring instructions. No firmware or HX711 interface is delivered by this CAD task.
13. **Nov9–10 tests:** first dry mate and verify all switch transitions with water absent; then run separate poppet hold tests, mated leak tests, manual-clamp closure and commanded pinch closure. Adjust stops and torque limits using measured loads. Check raised fill branch remains dry while drain is open. Recheck after any routing change. Collect demate spill separately and empty waste before overflow.
14. **Nov11–13 demonstration:** feed stays closed until independent seat AND latch switches are true. Condition to measured wall<15°C for5s, close drain to fill at least50mL, then close feed, open drain, verify zero residual head, unlatch and retract. Test serial-loss isolation within2s, reject false interlocks, perform20cycles and the nominal/±5mm/±1° repeated mates from the plan. Log failures and measured leakage. No pressurized gas, cryogen or flight qualification is part of this prototype.
